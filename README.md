# 🍲 Nashi Restaurant - Interactive Website

An **interactive restaurant website** built with **HTML, CSS, and JavaScript**.  
The website includes:

- A responsive homepage with featured offers
- Clickable **food items** that show a popup with the food name, price, and image
- Clickable **feature boxes** (Discount Voucher, Fresh Healthy Food, Fast Home Delivery) that display more details in a popup
- A footer with main links, support links, and a newsletter signup form

---

## 🖥️ Technologies Used

- **HTML5** for structure
- **CSS3** for styling
- **JavaScript** for interactivity
- **Font Awesome** for icons

---

## 🌟 Features

1. **Food Item Popups**
   - Click on food images to see the name, price, and photo in a popup.

2. **Feature Box Popups**
   - Click on any of the three feature boxes to see more details about each feature.

3. **Hover Effects**
   - Smooth hover effects for buttons, links, and images.

4. **Responsive Design**
   - Works well on desktop and tablet screens.
